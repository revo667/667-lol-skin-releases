# 667 Lol Skin

League of Legends skin changer for macOS (Apple Silicon) and Windows.

Download the latest version from [Releases](https://github.com/revo667/667-lol-skin-releases/releases/latest):

- **macOS:** `667.Lol.Skin_*_aarch64.dmg`
- **Windows:** `667.Lol.Skin_*_x64-setup.exe`

The app updates itself from this page.
